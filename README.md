One funny fortune-cookie line for an AI agent, in the voice of a fortune slip: the classic "lucky numbers" bit, with the twist that the numbers are tokens the agent will never get back.

## Run it

```sh
node main.ts
```

The program writes the fortune to `/output/entry.txt` (one line, 80 characters, inside the 1–140 gate).
